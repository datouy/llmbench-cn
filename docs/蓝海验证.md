# 蓝海项目验证报告（2026-10-26）

> 方法：GitHub Search API 实时检索（2026-10-26），每项结论都附搜索证据。
> 结论先行：`aicn` 的方向**已有人做过**（cc-switch 148.6k stars，桌面形态）；**`llmbench-cn` 经检索确认无直接竞品**，属真蓝海。

## 一、aicn 方向的诚实结论

| 检索 | 关键结果 |
|---|---|
| `codex config custom provider` | **[farion1231/cc-switch](https://github.com/farion1231/cc-switch) 148.6k stars**：跨平台桌面工具，All-in-One 管理 Claude Code / Codex / OpenCode / Grok Build 等工具的供应商配置切换 |
| `cursor 国内 模型 配置` | 无独立小工具，被 cc-switch 类大项目覆盖 |

**结论**：配置/切换这个需求空间已被 cc-switch 用桌面应用形态占据主流。aicn 不再自称蓝海，其差异化定位是：**零依赖 CLI（无需装桌面应用）+ 国产供应商数据 + 三协议实测 + 价格聚合**，作为 cc-switch 的轻量补充仍有存在价值。

## 二、llmbench-cn：验证过的蓝海

### 竞品检索证据

| 检索词 | 最接近结果 | 为什么不是竞品 |
|---|---|---|
| `llmbench in:name` | llmBench (49★)、ChemLLMBench (176★) | 只测本地 Ollama 运行时/化学领域，不测云供应商 |
| `llm benchmark in:name` | chinese-llm-benchmark (6.5k★) | **数据仓库**：他们测好发布结果，你不能用自己的密钥/网络自测 |
| `llm compare in:name,description` | ollama-grid-search (957★)、Local-LLM-Comparison-Colab-UI (1.1k★) | 桌面/Colab，且面向**本地模型**，不含国内云供应商与价格成本 |
| `llm latency test` | opencode-benchmark-dashboard (46★) | 仅针对 OpenCode 工具，非通用选型 |
| `llm price compare` | llm-price-compass (221★) | 只对比 GPU 云价格，不做模型实测 |

**空白确认**：没有任何工具同时满足「**你自己的网络 + 自己的密钥 + 国产云供应商 + 首 token 延迟 + 价格成本 + 客观任务通过率**」。llmbench-cn 就是做这件事。

### 为什么实用性高

- 每个国内 AI 开发者买模型前都要面对"DeepSeek 还是 Qwen 还是 GLM 还是豆包"的选择；
- 排行榜数据是别人网络下的，延迟与成本对自己的场景没有参考价值；
- 实测一次成本不到 1 分钱，1 分钟出结论。
